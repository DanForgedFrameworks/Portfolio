Forged Frameworks - review pack

Demonstration build - interactive learning activity

What these are. Each pack covers one scene of the module and shows its interaction states — carousel slides, open dialogs, quiz feedback, revealed figures. Within a pack, a whole number is a part (a primary view) and a decimal is a state within it, so 6.2 is the second state of the sixth part. Quote that number and we will both be looking at the same screen.

Open the reviewer to comment and pin notes directly onto a state, then save and send the file back. The PDF pack opens in a new tab if you would rather read, print or mark it up offline — it holds the same states in the same order.

About coverage. States are found automatically by walking each scene, so a pack shows what the walk reached. Some individual states may not appear — an unusual control can be missed — but the content and design on display should be represented across the pack. If something you expected to see is not here, please say so.
